# Leda PSS

English training interface for Leda Sport v2.02.

1. Place the original Leda package in `LedaSportXunLian_V202` (not included).
2. Run `python tools/build_english.py`.
3. Open `LedaSport-English/Start-English.cmd`.
4. On **Athletes**, assign up to two athletes per court. The first is blue; the second is red.
5. Press **Train**, then **Start** to begin.

Use **Sensor levels** to view impact readings and adjust thresholds (maximum 71). **Listen for hits** monitors sensors without starting the scoring timer.
