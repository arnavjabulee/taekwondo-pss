# Keyboard shortcuts

For UoBTKD Training Suite:

| Key | Action |
| --- | --- |
| Space | Start, pause, or resume court training or free-training tracking when its screen has focus. Ignored by the training shortcut while editing a field or while a dialog is open. |
| Escape | Close the active dialog, or return to the previous screen. Does nothing on the main menu. No longer toggles fullscreen. |
| Tab / Shift+Tab | Move focus forward/backward through controls. |
| Up / Down | Change a focused number field or dropdown selection. |

Left Alt and right Alt no longer trigger start, pause, or resume.

Standard Windows/input shortcuts remain available:

| Key | Action |
| --- | --- |
| Alt+F4 | Close the app. |
| Alt+Space | Open the window/system menu. |
| Ctrl+A / C / X / V / Z | Select all, copy, cut, paste, and undo in editable text fields. |

No other application-specific keyboard bindings were found in the inspected v2.02 host handler or the current interface. Enter is consumed by the legacy host handler; use the on-screen buttons rather than relying on Enter to submit a form.
