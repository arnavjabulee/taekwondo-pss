# Shortcuts

| Key | Action |
| --- | --- |
| Space | Start, pause or resume the active session; ignored while editing or in a dialog. |
| Escape | Close a dialog or return to the previous screen. In a spectator window, close the display. |
| F | Full screen in the spectator window. |
| Tab / Shift+Tab | Move between controls. |
| Alt+F4 | Close the focused window. |
